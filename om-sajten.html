Om sajten

Sajten är byggd med Claude, en AI-assistent från Anthropic, i verktyget Claude Code.

Tekniker

  • Kod: HTML, CSS och JavaScript, utan ramverk och utan byggsteg
  • Webbhotell: GitHub Pages
  • Karta: Leaflet med kartbilder från OpenStreetMap
  • Data: alla tips och kartpunkter i en JSON-fil
  • Offline: service worker som sparar sidorna i webbläsaren
  • Bilder: WebP i flera storlekar med JPG som reserv, lazy loading
  • Typsnitt: Dosis och Jost, lagrade på sajten (WOFF2)
  • Språk: fem språk med egen adress per språk (?lang=)
  • Tillgänglighet: WCAG 2.2 nivå AA
  • Tester: GitHub Actions med W3C:s HTML-validator, länkkontroll och axe
